# PushPop 推推爆

一款创新的卡牌推拉消除游戏，结合了俄罗斯方块的下落机制和连连看的消除玩法，带来全新的游戏体验！

## 🎮 游戏特色

### 核心玩法
- **抽牌**：点击牌堆最下方的卡牌加入手牌
- **出牌**：将手牌拖动到任意列的底部
- **消除**：3个或更多相同颜色的卡牌横向相连时自动消除
- **连锁反应**：消除后上方卡牌下落，可能触发新的消除
- **列左移**：消除后变为空列的行会自动左移补齐

### 游戏机制
- **20个关卡**：从简单到困难的关卡 progression
- **彩虹牌**：可以选择任意颜色的特殊卡牌
- **得分倍率**：部分关卡消除得分翻倍
- **自适应界面**：支持PC和手机端
- **流畅动画**：抽牌、消除、下落、左移都有平滑动画

## 📱 如何玩

### PC端
1. 点击牌堆最下方的卡牌抽牌
2. 点击手牌拖动到下方的出牌区
3. 松开鼠标将卡牌插入对应列

### 手机端
1. 点击牌堆最下方的卡牌抽牌
2. 触摸手牌并拖动到下方的出牌区
3. 松开手指将卡牌插入对应列

## 🎯 游戏目标

- **通关所有关卡**：从入门到大师，挑战自己的策略能力
- **获得高分**：利用连锁消除和得分倍率获取更高分数
- **掌握技巧**：合理使用手牌槽，规划出牌顺序，创造更多连锁消除

## 🌟 游戏技巧

1. **观察底部**：优先处理底部的卡牌，避免堆积过高
2. **保存彩虹牌**：在关键时刻使用彩虹牌创造消除机会
3. **规划连锁**：尝试在不同列创造消除条件，触发连锁反应
4. **利用左移**：消除整列后会左移，可能带来新的组合机会
5. **合理分配手牌**：根据当前局面选择最佳出牌时机
